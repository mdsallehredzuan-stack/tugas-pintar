# Tugas Pintar

Aplikasi to-do list ringkas dalam Bahasa Melayu.

## Ciri
- Tambah, siap/tidak siap, dan padam tugas
- Penapis Semua / Belum siap / Siap
- Progress bar automatik
- Simpan data dalam `localStorage`
- Responsive untuk desktop dan telefon

## Jalankan
Buka `index.html` dalam pelayar atau deploy terus ke Vercel.
